发现的问题与修复

  1. 梦境锚点会被示例污染

    问题：用户只说了办公楼、14 层、电梯口、邮件、小台灯时，系统有时会把历史示例里的“融化按钮”带进结果，破坏可信度。

    修复：扩展中文锚点提取，增加 unsupported melted detail 清理逻辑，让 stuck_elevator 相关提示只使用真实输入里出现过的细节。

    • 新增测试覆盖：未输入“融化”时不得出现；用户确实输入“融化按钮”时要保留。
    • 代表提交：7e05b4c Fix Dream QA anchor fidelity

  2. Today Tip 没有优先吸收用户回答

    问题：用户在追问回答里给出具体行动，例如“今天先写邮件第一句话”，结果仍可能偏向情绪模板。

    修复：在 _polish_today_tip 中增加 answer-aware shaping：当回答里包含邮件、草稿、演示等明确任务时，让 interpretation、today_tip、tiny_action 优先围绕这个具体行动生成。

    • Chrome 验证结果：最终 Tip 明确引用“邮件”和“第一句话”。
    • 代表提交：8b45257 Prioritize concrete answer tips

  3. 长等待时用户不知道系统是否在工作

    问题：点击继续或发送回答后，如果后端较慢，页面缺少即时反馈，用户容易误以为卡住。

    修复：增加 processing notice 与 processing note。提交梦境时显示“正在整理梦境线索”，生成 Tip 时显示“正在检查梦境锚点、你的回答和安全边界”。

    • 后续 Chrome 验收发现 event-level JS 会触发 Gradio Number 输入错误，因此最终改成 DOM listener，不再挂在 Gradio .click(js=...) 上。
    • 代表提交：f84f819, ed9b284, a2c28e0

  4. 复制结果按钮不是真正复制

    问题：用户生成 Today Tip 后，需要方便复制结果回看或分享。

    修复：增加 navigator.clipboard.writeText 路径，并保留浏览器阻止复制时的可恢复提示。

    • Chrome 验证结果：剪贴板文本长度 1299，包含 Today Tip 与“邮件”。
    • 代表提交：6fb9df2 Make result copy button use clipboard

  5. “换个角度”语义不够明确，追问片段可能截断

    问题：按钮文案容易让人误解为重写结果，不是重新追问；中文回答片段还可能截成“今天可。”这种不自然片段。

    修复：按钮改为“再追问一下”和“换个追问角度”；中文 answer snippet 截断长度放宽，并尽量在句末截断。

    • Chrome 验证结果：新追问保留完整“今天可以先写第一句话，不一定马上发出去”。
    • 代表提交：11bc374 Clarify another-angle questions

  6. 空输入错误只在顶部提示，不够贴近输入区

    问题：用户不输入任何梦境就点继续时，错误只靠顶部 notice，不够明确，也不利于辅助技术感知。

    修复：在输入区下方增加内联错误提示，并使用 role="alert"。

    • Chrome 验证结果：空输入后出现 “Dream note needs at least one sentence, image, or voice clue before Continue.”
    • 代表提交：510df9b Show inline dream input errors

  7. 真实 Chrome 下“发送回答”会崩溃

    问题：Chrome 真实点击“发送回答”时，Gradio 抛出 type str doesn't define __round__ method。根因是 processing feedback 挂在 event-level JS 上后，Number 输入在真实浏览器路径中以字符串进入 gr.Number.preprocess。

    修复：尝试数值 coercion 后仍复现，最终改成更稳的方案：processing feedback 使用 Blocks(js=VOICE_JS) 里的 class-based DOM listener，Gradio 事件本身不再带 processing JS，从根上避免污染事件输入。

    • Chrome 复测结果：回答提交成功生成 Today Tip，无 __round__ 错误。
    • 代表提交：a5fd37d, fd4afbc, ed9b284

  8. 追问按钮的处理中提示语义不准

    问题：点“换个追问角度”时，processing 文案仍然说“正在把追问回答整理进今日小 Tips”，与实际行为不一致。

    修复：把追问类按钮从 Tip processing 分离出来，显示“正在换一个追问角度”和“正在保留你的回答和梦境锚点，只重新生成一个更贴近当下的追问”。

    • Chrome 验证结果：换角度时出现正确 processing 文案，并成功回到追问态。
    • 代表提交：a2c28e0 Clarify question processing feedback
